Обо мне

Специалист по информационной безопасности — фокус на SOC, Web Security и DFIR

Я выпускник Уральского федерального университета по направлению «Информационная безопасность». Основной профессиональный фокус — работа в SOC, анализ событий и журналов безопасности, первичный triage инцидентов, web security и цифровая криминалистика.

Практический опыт включает анализ защищённости веб-приложений по OWASP Testing Guide, классификацию уязвимостей по OWASP / CWE, работу с Burp Suite, а также анализ событий и журналов безопасности в учебных и практических средах.

В рамках ВКР я разработал TRACE — автоматизированное рабочее место для расследования инцидентов ИБ: сбор, импорт и анализ цифровых артефактов Windows, проверка целостности, ведение дел, журналирование действий и формирование отчётов.
